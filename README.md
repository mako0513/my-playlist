# 🎵 マイプレイリスト

YouTubeのURLを貼るだけで曲をため、Mac・iPhoneで連続再生できる自分専用プレイリストアプリ。
ビルド不要の静的Webアプリ（HTML/CSS/JavaScriptのみ、外部ライブラリなし）。

## 使い方

1. アプリを開く（公開URLか、ローカルなら下記「ローカルで動かす」）
2. YouTubeの動画URL（`watch`・`youtu.be`・`shorts`・`music.youtube.com` いずれも可）を貼って「追加」
3. 曲名をタップで再生。曲が終わると自動で次へ進む
4. 🔀シャッフル・🔁リピート（全曲→1曲→オフの順で切替）
5. ↑↓で並べ替え、✕で削除

プレイリストは複数作れる（＋で新規、✏️で改名、🗑で削除）。

## Mac → iPhone にプレイリストを渡す

1. Macで📤（共有URLをコピー）を押す
2. コピーされたURLをAirDropやLINEで自分のiPhoneに送る
3. iPhoneでそのURLを開くと「取り込みますか？」と出るので取り込む

データはサーバーに保存されず、各端末のブラウザ内（localStorage）に保存されます。
曲リストがネット上に公開されることはありません。

## iPhoneでアプリのように使う

Safariで開く →「共有」→「ホーム画面に追加」。アイコンから全画面で起動できます。

## 制約

- **iPhoneで画面をロックすると再生は止まります**（YouTubeの仕様）。画面を点けたままなら連続再生できます。
- 削除済み・埋め込み禁止の動画は自動でスキップし、リストに⚠を付けます（YouTubeで開くリンク付き）。
- 動画のダウンロードはしません（YouTube埋め込み再生のみ）。

## ローカルで動かす

```bash
python3 -m http.server 8765 -d .
# ブラウザで http://localhost:8765/index.html を開く
```

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目（ダーク・モバイル対応） |
| `lib.js` | URLからの動画ID抽出・共有URLのエンコード/デコード（純粋関数） |
| `app.js` | 状態管理・再生制御・共有・描画 |
| `test/lib.test.js` | lib.js の単体テスト（`node --test test/lib.test.js`） |
